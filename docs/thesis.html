📝 심층 투자 논리 리포트

Claude Code 에서 /thesis 종목명 으로 생성한 15단계 리포트(웹 검색 증거 포함). 종목을 누르면 상세에서 본문을 보여줍니다.

① 무슨 일이 벌어지고 있는가 — 주도 그룹

종합 RS(1M 20%·3M 40%·6M 20%·12M 20%) 순. 확산 = 그룹 내 RS≥70 종목 비중, 4주Δ = 4주 전 스냅샷 대비 그룹 평균 RS 변화. EPS↑ = 커버리지 종목 중 4주간 EPS(E) 상향 비중, OPM↑ = 최근 분기 영업이익률이 전년동기보다 높은 종목 비중. 행을 누르면 재료·기업 비교로 내려갑니다.

② 왜 오르는가 —

인과 사슬 초안 (Earnings Transmission Chain)

    증거 사다리 — 증권사 리포트 30일 + DART 수주·공급계약 공시 60일

    L5 데이터(DART 단일판매ㆍ공급계약 공시 = 실제 주문, 리포트의 수주·판가·출하·증설) › L4 고객사 › L3 산업·경쟁사 › L2 애널리스트 › L1 회사 주장. 리포트 태깅은 키워드 규칙이라 참고용, DART 공시는 원문 링크로 열립니다. 여러 계층에서 같은 이야기가 나올 때가 가장 강한 아이디어입니다.

    뉴스 헤드라인 7일

    매크로·주도섹터 텍스트 언급 14일

    ③ 누가 가장 많이 버는가 — 그룹 내 기업 비교

    자동점수 = 15항목×2점(30점), 아래 작은 숫자는 전회 실행 대비 변화(업종 기준). 점수 추이는 실행일별 기록(0~30 고정 축). Core = 규모·가시성 우위, Beta = 변동성·영업레버리지 우위(업종 피어 대비). 열 머리글로 정렬, 행을 누르면 종목 논리 템플릿으로.

    체크리스트 — 자동 15항목 + 수동 4항목

    자료가 없는 항목은 "-"(0점 처리). 수동 항목은 직접 선택하면 브라우저에 저장됩니다.
